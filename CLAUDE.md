# Claude Code Instructions

Read `AGENTS.md` before performing any work.

For repositories adopting this platform, also read:

1. `PROJECT_CONTEXT.md`
2. architecture documentation
3. relevant source files
4. current Git status

Default behavior:

- Explore before editing.
- Plan before high-impact changes.
- Prefer incremental implementations.
- Run validations after changes.
- Never access secrets or private SSH keys.
- Ask before dependencies, migrations, Docker, Git commits, pushes or deployments.
- Communicate explanations in Spanish and write code in English.
