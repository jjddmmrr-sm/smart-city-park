# Project Audit

When auditing a project:

1. Read `AGENTS.md`, `PROJECT_CONTEXT.md` and architecture documentation.
2. Inspect Git status and repository structure.
3. Identify stack, modules and system boundaries.
4. Review security, tests, CI, documentation and dependency hygiene.
5. Do not modify files.
6. Produce:
   - executive summary;
   - architecture map;
   - critical risks;
   - maturity score;
   - prioritized recommendations;
   - 30-day improvement plan.
